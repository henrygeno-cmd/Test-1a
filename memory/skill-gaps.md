# Skill Gaps

Requests that no existing skill covered. Appended by `skills/skill-acquisition/`
after the task is already done — logging never comes before the work.

`review-agent` reads this weekly. Three or more entries of the same shape become
a proposal for a new skill folder. Match on the shape of the task, not the
wording: "make a thumbnail," "design a story graphic," and "need a header image"
are one gap.

**Format:**

```
## YYYY-MM-DD — <short name for this kind of task>
**Request:** <what was actually asked, one or two lines>
**Business/context:** <business key, or "personal"/"school"/"n/a">
**Routed to:** <skill borrowed from, or "nothing — handled ad hoc">
**How it went:** <what was done, and how well it worked>
**Would a skill help?** <yes/no/maybe + what it would specify>
**Seen before:** <count, or "first time">
```

When a shape hits 3+, add this line at the top of the entry:

`**ESCALATE → review-agent: recurring (N×)**`
