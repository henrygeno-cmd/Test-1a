# Swipe File

Copy that worked. Appended by `skills/content-agent/` when something performs or
when I pick a variant and confirm it was right.

Read this before writing new copy for a business — reuse the winning *structure*
and angle, never the exact text. `review-agent` checks whether the patterns here
contradict what `content-agent/SKILL.md` says to do; when they do, the evidence
wins and the skill file gets a proposed edit.

**Format:**

```
## YYYY-MM-DD — <business> — <format>
**Copy:** <the actual text, verbatim>
**Angle:** <the lever it pulled — e.g. authority, specific number, contrarian>
**Result:** <CTR, replies, sales, or "picked it, no data yet">
**Why it worked:** <one line>
```

Formats: hook, headline, subject line, ad copy, caption, etsy title, etsy
description, landing section, deck opener, deck ask, tagline.
