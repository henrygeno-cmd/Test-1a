# Learnings

Read at the start of every session. This is the standing context: preferences,
corrections, decisions already made, and things that turned out to be true.

Append new entries at the bottom. Don't rewrite old ones — if something is
superseded, add a new entry that says so. `review-agent` prunes this file
during weekly review, and only by proposing a diff.

**Log an entry when:**
- I correct you on something (tone, format, an assumption, a fact)
- I state a preference or make a standing decision
- Something worked notably well or failed notably badly
- A fact about a business, a client, or a tool turns out to matter

Don't log routine task completions. This is signal only.

**Format:**

```
## YYYY-MM-DD — <short title>
**Context:** <business key or "personal"/"school"/"general">
**What happened:** <one or two lines>
**Learning:** <the rule to apply next time — write it as an instruction>
**Applies to:** <which skill(s), or "all">
```
